# 霍格沃茨人生 · 1991年暑假序章 Phase 1

## 运行
用 VS Code Live Server 打开 `prologue.html`（推荐），或在项目根目录执行 `python -m http.server 8000` 后访问 `http://localhost:8000/prologue.html`。不可直接使用 `file://` 打开，因为浏览器可能阻止 fetch JSON。

## 内容
- 1991-07-25 至 1991-09-01，26条原创生活事件、7次关键决定。
- 4种家庭背景，家庭揭示事件会根据背景变化。
- 逐条继续、跳到下一决定、每1.1秒自动推进、自动暂停、浏览器本地存档、恢复、重新开始。
- 对角巷、魔杖店、宠物选择、九又四分之三站台、列车初遇。
- 完成后可将角色姓名、学院预选、序章记录与选择导入既有游戏存档。旧版页面点击「读取存档」即可继续。

## 数据保留
以 `hp_life_game_seven_year_life_phase1` 为基础完整复制；原有 `data/*.json`、`js/*.js`、`css/style.css`、`index.html` 原功能均保留，仅添加序章页面和模块，并给原页面加了入口。旧数据没有删除、裁剪或重写。序章数据独立存于 `data/prologue_1991.json`。

## 现阶段边界
- 这是可玩序章的第一版，剧情是原创短事件，未复制小说正文。
- 目前序章中的宠物、数值、选择保存于 `player.prologue`；它们尚未全部映射到家庭经济、库存、宠物或NPC引擎。
- 魔杖店为故事选择，尚未实现木材、杖芯和长度的完整生成。
- 学院在序章页面是旧版主线的衔接预选，正式分院仪式待下一阶段实现。
- 主线旧版 `schoolEngine` 从 1991-09-01 开始；序章日期由新叙事引擎单独管理。
- 本地存档存于浏览器 localStorage，不会跨浏览器同步。
- 原版游戏已有存档不会在序章期间被覆盖；只有完成序章后点击导入并确认，才会覆盖旧版主线存档。
